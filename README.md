# MILE AI Assistant

MILE is a personal AI assistant built with Python that provides voice-based interaction, AI-powered responses, and desktop automation.

## Features

- Voice command interaction
- Speech recognition
- Text-to-speech responses
- AI-powered conversations
- Desktop automation
- System utilities and controls
- PyQt5 graphical interface
- Support for local AI models through Ollama

## Tech Stack

- Python
- PyQt5
- Speech Recognition
- Text-to-Speech
- Groq API
- Ollama
- Gemma

## Purpose

MILE was developed as a personal desktop assistant to explore AI integration, voice interfaces, automation, and desktop application development.
